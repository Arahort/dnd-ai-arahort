# Проверка версии 0.1.0
Автор: Arahort — arahort.pro, alex@arahort.pro. Дата: 24 октября 2026.
Локальная проверка выполнена на Windows x86_64. Целевая ОС установки — Ubuntu 24.04 x86_64; её первый прогон выполняется отдельно по server-test.txt.
## Выполнено локально
- TypeScript noEmit, Vite production build и минификация серверных entrypoints без sourcemaps.
- 58 тестов приложения под Node.js 22.22.1: cookie-сессии, CSRF, права администратора/игрока/наблюдателя, инвайты, русский FTS, обработка ошибок AGY, учёт фоновых процессов и режим обслуживания.
- Интеграция настоящего PostgreSQL WASM через TCP-протокол pg с приложением, HTTP и Socket.IO. Экспорт, preview и импорт проверены на фактических SQL-данных, включая NPC, владельцев, личные сообщения, голосования, инициативу, медиа и флаги уже выполненных действий.
- 17 Python-тестов дистрибутива и обновлятора: состав релиза, ограничения протокола, резервирование, откат, сохранение новых данных после попытки открыть запись, целостность копий, перенос AGY symlink, прокси, SSH OAuth и постоянный maintenance-файл.
- Синтаксис Python/Bash, YAML и корректные LF-переносы shell/Python файлов.
- Чистая установка production-зависимостей готового app/ через npm ci с отключёнными lifecycle scripts; npm audit не сообщает известных уязвимостей на момент проверки.
- Запуск готовых admin-cli.mjs и index.mjs вне закрытых исходников. Реальный Chrome: вход, создание приглашения, регистрация игрока, повторная загрузка сессии, ограничение админки, desktop/mobile layout. Экран квот проверен на контролируемом ответе; AGY при этом не запускалась.
- Состав готовой app/ и архивов: без исходных TS/TSX, sourcemaps, node_modules, .env, аккаунтов, действующих партий и прежних proxy-параметров. Лицензии серверных и включённых в bundle браузерных библиотек сохранены.
## Что проверяется на тестовом сервере
Docker Engine/Compose, systemd, Linux-права bind mounts, Caddy/сертификат, native PostgreSQL 16 с несколькими backend-процессами, Google OAuth внутри контейнера, действующий прокси, реальные ответы Gemini и generate_image, Microsoft Edge TTS, обновление образов и восстановление на копии установки.
PostgreSQL WASM в интеграционном тесте использует один backend; этот прогон не является замером конкуренции, производительности или минимальной RAM. Реальных запросов модели и озвучки локальная проверка не выполняла. Готовность Google-сети, аккаунта и конкретной модели подтверждается успешным игровым ходом, а не health или отчётом квоты.
Перечень унаследованных сторонних материалов и состояние подтверждения прав находятся в THIRD-PARTY-NOTICES.md; собственная некоммерческая лицензия относится к приложению.
