# Проверка версии 0.1.0
Автор: Arahort — arahort.pro, alex@arahort.pro. Дата: 24 октября 2026.
Локальная проверка выполнена на Windows x86_64. Целевые ОС установки — Ubuntu 22.04, 24.04 и 26.04 LTS x86_64. Версии и соответствующие репозитории Docker проверены тестами установщика; реальные установки на каждой ОС проверяются отдельно по server-test.txt.
## Выполнено локально
- TypeScript noEmit, Vite production build и минификация серверных entrypoints без sourcemaps.
- 103 теста приложения под Node.js 22.22.1: cookie-сессии, CSRF, права администратора/игрока/наблюдателя, инвайты, пароль из одного символа, перенос аккаунтов/точных логинов/хешей, архивы двух версий, русский FTS, обработка ошибок AGY, учёт фоновых процессов, режим обслуживания, структурированные квоты, SVG и текущий протокол Edge.
- Интеграция настоящего PostgreSQL WASM через TCP-протокол pg с приложением, HTTP и Socket.IO. Экспорт, preview и импорт проверены на фактических SQL-данных, включая NPC, владельцев, личные сообщения, голосования, инициативу, медиа и флаги уже выполненных действий.
- 27 Python-тестов дистрибутива и обновлятора: поддержка трёх Ubuntu LTS, состав релиза, встроенный репозиторий автора, ограничения протокола, резервирование, откат, сохранение новых данных после попытки открыть запись, целостность копий, перенос AGY symlink, прокси, SSH OAuth, постоянный maintenance-файл, любой непустой пароль в установщике/CLI и поток прогресса до завершения дочернего процесса. Отдельно доказано, что stderr не попадает в бинарную резервную копию. Все 27 выполнены под Python 3.13.5; под 3.10.20, 3.12.4 и 3.14.6 выполнены 26, проверка YAML пропущена из-за отсутствия необязательного PyYAML в этих тестовых средах.
- Проверены синтаксис и выполнение служебных скриптов на Python 3.10 / 3.12 / 3.14. Для будущих запусков GitHub Actions добавлена матрица реальных Ubuntu-контейнеров 22.04 / 24.04 / 26.04 с проверкой их /etc/os-release; эта CI-матрица ещё не выполнялась, поскольку репозиторий не создан.
- Синтаксис Python/Bash, YAML и корректные LF-переносы shell/Python файлов.
- Чистая установка production-зависимостей готового app/ через npm ci с отключёнными lifecycle scripts; npm audit не сообщает известных уязвимостей на момент проверки.
- Запуск готовых admin-cli.mjs и index.mjs вне закрытых исходников. Реальный Chrome: вход, создание приглашения, регистрация игрока, повторная загрузка сессии, ограничение админки, desktop/mobile layout. Квоты проверены как на fixture, так и настоящей встроенной JSON-командой AGY с нулевыми ходами и токенами; отображаются четыре полосы двух групп моделей.
- В новом готовом билде отдельно проверены bootstrap администратора через admin-cli.mjs с паролем из одного символа и фактические вход/регистрация с таким паролем в Chrome; production npm ci/audit выполнены в отдельной временной папке.
- Исходный opt/dnd: production build и 6 тестов нового экспортёра. Новый POST подтверждает собственный пароль администратора, отклоняет подставленный userId/мастер-пароль/чужой origin, сохраняет repeatable-read снимок и проверяет медиа. Старый читаемый экспорт сохранён.
- Независимый сквозной прогон настоящего экспортёра opt/dnd → ZIP v2 → HTTP-импорт через PostgreSQL WASM: 9 аккаунтов, 7 создано, 2 существующих переиспользованы; текущие пароли, админ-права и disabled сохранены. Подтверждены повторное использование аккаунтов между партиями, короткие и точные Unicode-логины, вход старым паролем с последующим обновлением хеша, ссылки NPC/whisper/poll/memory и обе картинки. Ошибка вложенной ссылки откатывает новые аккаунты, связи и партию. Новая миграция проверена поверх прежней схемы v1.
- Готовая app/ проверена в Chrome: ZIP исходного экспортёра загружен реальной формой импорта, существующий Arahort сохранён, созданы 8 остальных аккаунтов, показан отчёт. Вход перенесённого пользователя со старым паролем успешен. Диалог импорта перенесён в body для независимости от backdrop-filter родительской панели; desktop/mobile границы окна и отсутствие горизонтального переполнения проверены.
- Реальная локальная AGY 1.4.6 через действующий VPN: короткий запрос Gemini 3.8 Flash High, создание снаряжения, проверка персонажа, начало партии и дополнение мира через HTTP/Socket.IO. Сохранённая SVG-карта с ошибочно повторённым закрывающим маркером отображается; реально сгенерированная иллюстрация 1376×768 распознана по Windows-пути и открыта в браузере.
- Реальный Edge Read Aloud с Sec-MS-GEC v2: получен MP3 через транспорт и через HTTP API приложения; Chrome успешно декодировал аудио длительностью 10,584 секунды. Старый клиент с v1, получавший 403, удалён.
- Состав готовой app/ и архивов: без исходных TS/TSX, sourcemaps, node_modules, .env, аккаунтов, действующих партий и прежних proxy-параметров. Лицензии серверных и включённых в bundle браузерных библиотек сохранены.
## Что проверяется на тестовом сервере
Docker Engine/Compose, systemd, Linux-права bind mounts, Caddy/сертификат, native PostgreSQL 16 с несколькими backend-процессами, Google OAuth внутри контейнера, действующий прокси, реальные ответы Gemini и generate_image, Microsoft Edge TTS, обновление образов и восстановление на копии установки.
PostgreSQL WASM использует один backend; этот прогон не является замером конкуренции, производительности или минимальной RAM. Локальные запросы Gemini и Edge подтверждают работу в текущем Windows/VPN-окружении. На Linux нужно отдельно проверить контейнер, новый Google-вход и маршрут прокси. Готовность Google-сети, аккаунта и конкретной модели подтверждается успешным игровым ходом, а не health или отчётом квоты.
Собственная некоммерческая лицензия относится к приложению; тексты сторонних лицензий сохранены в licenses/.
## Первый серверный прогон
На Ubuntu 22.04.2 x86_64 с Python 3.10.12, Docker 27.2.1 и Compose 2.29.2 успешно установлен первоначальный образ 0.1.0 до изменения парольной политики. Native PostgreSQL 16 и приложение healthy, служба обновлений active, HTTPS через Caddy доступен по внешнему домену; внешний /api/health отдельно вернул ok=true, maintenance=false. В этом режиме TCP 8080 на хосте не публикуется.
У существующей Amnezia сохранились ID контейнера и время запуска. В предоставленном снимке простоя: приложение 76,04 МиБ, БД 33,64 МиБ, Caddy 12,5 МиБ; доступная RAM хоста 1309 МиБ, свободный диск 7,5 ГБ. Эти значения не являются замером игровых ходов или минимальными требованиями. AGY внутри контейнера показывает авторизованный аккаунт; успешная генерация, арт и Edge на этом VPS ещё не подтверждены.
