# Перенос партий и пользователей
Автор: Arahort — arahort.pro, alex@arahort.pro.
## Подготовка
Установи актуальный билд на новом сервере. Для исходного проекта обнови старый сервер до версии с кнопкой «Перенос». Перед выгрузкой дождись окончания ходов Мастера и генерации изображений.
Архив содержит личные сообщения и хеши паролей пользователей приложения. Храни его приватно и передавай только администратору своего сервера.
## Экспорт с исходного сервера
1. Войди администратором и открой нужную партию.
2. В верхней панели нажми «⬇ Перенос».
3. Введи собственный пароль этого аккаунта администратора и нажми «Скачать архив переноса». Мастер-пароль для этой операции не подходит.
4. Сохрани ZIP на своём компьютере. Для каждой партии скачивается отдельный архив.
Эта кнопка создаёт переносимый формат 2: настройки, мир и сюжет, дневник, сводки, день и ход, инициатива, персонажи и NPC, сообщения, память, изображения и связанные аккаунты. В аккаунты входят также ушедшие авторы сообщений, адресаты личных сообщений и участники голосований.
Обычный прежний экспорт исходного проекта остаётся читаемым архивом для просмотра. Для загрузки на новый сервер нужен ZIP именно от кнопки «Перенос».
## Импорт на новый сервер
1. Войди администратором, открой «Партии и архивы» → «Импорт партии».
2. Выбери ZIP и нажми «Загрузить и проверить».
3. Проверь название и план переноса пользователей. По умолчанию выбран режим «Автоматически по логину».
4. Нажми «Создать партию из архива» и дождись отчёта. В нём указано, какие пользователи созданы, а какие существующие использованы.
5. Нажми «Открыть партию». Проверь сообщения, карточки, NPC, память, карту, изображения, мировой день и инициативу. Затем выполни настоящий ход.
## Совпадение логинов и пароли
- Если в архиве и на новом сервере есть `Arahort`, партия и все ссылки на исходного `Arahort` привязываются к уже существующему. Его текущий пароль, права администратора и отключённое состояние сохраняются.
- Если логина ещё нет, он создаётся с прежним паролем из архива. Новый пользователь получает обычные права; создатель партии сохраняет полномочия ведущего своей партии.
- Совпадение логина точное, включая регистр. `Arahort` и `arahort` считаются разными логинами, как при обычном входе.
- Если нужен другой существующий аккаунт, администратор может выбрать его вручную перед импортом. Двух разных участников нельзя объединить в один аккаунт.
- При переносе нескольких партий с одного сервера уже перенесённые аккаунты используются повторно. Смена пароля на новом сервере не отменяется очередным импортом.
Пароли не восстанавливаются в открытом виде. Для старого формата хеша предусмотрена совместимая проверка; после первого успешного входа хеш автоматически обновляется, а сам пароль остаётся прежним.
Импорт всегда создаёт отдельную новую партию. Повторная загрузка того же ZIP создаст ещё одну партию, но не дубликаты уже связанных пользователей. При ошибке создание партии, новых аккаунтов и связей откатывается целиком.
## Форматы и ограничения
Формат 2 переносит пользователей и пароли. Формат 1 этой редакции по-прежнему импортируется с ручным сопоставлением существующих аккаунтов. Старые читаемые ZIP исходного проекта нужно выгрузить заново через «Перенос».
Лимиты: ZIP до 64 МиБ, распакованные данные до 128 МиБ, один файл до 32 МиБ. Между предварительной проверкой и импортом отведено 15 минут; после истечения срока загрузи архив повторно.
